## 目标：给 zcode-theme 注入器加背景图片支持

在现有 CSS 变量换肤基础上，支持用本地图片做全窗口背景（CDP 注入，不动 app）。

### 实现（核心改动仅 `zcode-theme.mjs`）

**1. 环境变量接口**（与现有 `ZCODE_THEME` 风格一致，经启动器/环境天然透传）：
- `ZCODE_BG_IMAGE=<路径>` — 背景图片（png/jpg/jpeg/webp/gif，按扩展名定 mime）；不设置 = 维持纯色现状
- `ZCODE_BG_OPACITY=60` — 图片可见度 0–100，默认 60

**2. 注入 CSS 结构**（基于已探明的 DOM）：
```css
/* 主壳: 背景图（cover 铺满, 固定不随内容滚动） */
div.flex.h-dvh.flex-col.overflow-hidden {
  background-image: url("data:<mime>;base64,...");
  background-size: cover; background-position: center; background-repeat: no-repeat;
}
/* 可读性遮罩: 聊天主区 + 右侧面板 + 侧栏,
   主题色半透明(alpha = 100-可见度), 深浅色主题自动跟随 */
#content section.rounded-xl,
.side-pane-open-tab-shell,
#sidebar {
  background-color: color-mix(in oklab, var(--color-background) 40%, transparent);
}
```

**3. 图片处理**（Node 内置模块，仍零依赖）：
- 顶层 `buildBgCss()`：`readFile` → base64 → `data:<mime>;base64,...` 嵌入 CSS（避开 `file://` 权限问题）
- 文件不存在 / 读取失败 / 超过 10MB → 警告并优雅回退纯色模式
- 更新文件头用法注释
